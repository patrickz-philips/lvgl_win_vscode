# 使用说明

本文档说明 6 个项目模块的模拟器操作和公开集成 API。构建方法参见[构建说明](构建说明.md)。

## 启动项目

在仓库根目录执行命令，运行参数必须与已构建的项目和配置一致：

```batch
build.bat SLIDE_PLAYER Debug
run.bat SLIDE_PLAYER Debug
```

公共 SDL 主机注册了鼠标、滚轮和键盘输入。关闭 SDL 窗口即可结束程序；随后 `run.bat` 会等待按键再关闭控制台。

## 项目操作

### Hair Dryer

```batch
build.bat HAIR_DRYER Debug
run.bat HAIR_DRYER Debug
```

使用鼠标操作右侧控制面板：

- `Start`/`Stop`：启动或停止当前灯带动画。
- `Ionizing`：切换负离子配色效果。
- `Low`、`Mid`、`High`：选择动画速度。
- `Cold`、`Warm`、`Hot`：选择温度配色。
- `Style Breathe`、`Style Wave`、`Style Pulse`：选择动画模式；切换模式会停止当前运行状态。

Debug 在运行时从仓库读取 PNG；Release 通常使用已编译的 C 资源。模块头文件将界面布局设为 800 x 720。

### Smart Shaver

```batch
build.bat SMART_SHAVER Debug
run.bat SMART_SHAVER Debug
```

按住鼠标左键水平拖动可在四个 320 x 640 页面之间切换。第一页包含 clean、replace 和 ready 控件，第二页包含状态和设置控件，其余页面是占位页面。

### Cheetah

```batch
build.bat CHEETAH Debug
run.bat CHEETAH Debug
```

数值初始为 0，范围限制为 0 到 100。按上/右方向键加 1，按下/左方向键减 1；SDL 鼠标滚轮编码器也可以修改当前聚焦的数值。

### Slide Player

```batch
build.bat SLIDE_PLAYER Debug
run.bat SLIDE_PLAYER Debug
```

按住鼠标左键水平拖动。向左手势显示下一张，向右手势返回上一张；到达首尾后不会循环。底部显示当前 `序号/32`。

### Battery Monitor

```batch
build.bat BATTERY_MONITOR Debug
run.bat BATTERY_MONITOR Debug
```

按住鼠标左键向左或向右拖动，在两页之间切换。模拟器启动时显示示例数据：第一页为温度、电池/VBUS/系统电压和电量；第二页为充电、放电、待机、VBUS 标志和充电状态。

### Accelerometer Data

```batch
build.bat ACC_DATA Debug
run.bat ACC_DATA Debug
```

桌面入口只初始化 UI，不会自动生成传感器数据，因此宿主代码推送样本前，曲线保持初始状态。当前模拟器界面没有可点击的录制按钮；boot-button API 用于嵌入式宿主或其他输入适配层。

曲线保留 125 个点；以 20 ms 周期推送时，对应 2.5 秒显示窗口。

## 集成 API

所有 UI 更新函数都应在 LVGL 线程调用。发送数据前先初始化对应模块。

### 模块初始化

| 模块 | 公开入口 |
| --- | --- |
| Hair Dryer | `hair_dryer_ui_init()` |
| Smart Shaver | `smart_shaver_ui_init()` |
| Cheetah | `cheetah_ui_init()` |
| Slide Player | `slide_player_ui_init()` |
| Battery Monitor | `battery_monitor_ui_init()` |
| ACC Data | `acc_data_ui_init()` |

这些模块会保存 LVGL 对象或定时器状态，且没有提供反初始化 API。每个 LVGL 生命周期只初始化一次所选模块。

### Hair Dryer 灯效

`projects/hair_dryer/inc/led_strips_discolor.h` 提供纯色、呼吸、轮转、波浪和脉冲控制。启动动画前先调用 `led_strips_discolor_init()`。传给初始化和分段模式 API 的 LVGL 对象数组必须在动画定时器存续期间保持有效；删除这些对象前先调用对应的停止 API。

速度、颜色和动画类型使用同一头文件中的 `LED_SPEED_*`、`LED_COLOR_*` 和 `LED_TYPE_*` 常量。

### Battery Monitor 数据

包含 `projects/battery_monitor/inc/battery_monitor.h`，初始化界面并传入完整数据：

```c
battery_monitor_data_t data = {
    .temperature = 26,
    .bat_voltage_mv = 3850,
    .vbus_voltage_mv = 5000,
    .system_voltage_mv = 3300,
    .bat_percent = 78,
    .is_charging = 1,
    .is_discharge = 0,
    .is_standby = 0,
    .is_vbus_in = 1,
    .is_vbus_good = 1,
    .charge_status = "Fast charge",
};

battery_monitor_ui_init();
battery_monitor_set_data(&data);
```

结构体会被复制，但 `charge_status` 是指针，界面使用期间字符串存储必须保持有效。向 `battery_monitor_set_data` 传入 `NULL` 不执行更新；状态指针为 `NULL` 时显示 `Unknown`。

### Accelerometer Data 数据

包含 `projects/acc_data/inc/acc_data.h` 并初始化界面：

```c
acc_data_ui_init();
acc_data_set_battery_percent(82);
acc_data_push_sample(x_raw, y_raw, z_raw);
```

`acc_data_push_sample` 接收有符号 16 位原始 LSB 数据。每隔 `ACC_DATA_DISPLAY_PERIOD_MS`（20 ms）调用一次，可保持设计的显示窗口。

boot-button 状态机向宿主返回操作：

```c
acc_data_record_action_t action = acc_data_handle_boot_button();
if(action == ACC_DATA_RECORD_ACTION_START) {
    /* Start recording samples. */
}
else if(action == ACC_DATA_RECORD_ACTION_STOP) {
    /* Stop and save recorded samples. */
}
```

保存完成后调用 `acc_data_set_save_finished(true)` 或 `acc_data_set_save_finished(false)`；存储不可用时调用 `acc_data_set_sdcard_missing()`。这些函数只更新 UI 状态，文件录制和 SD 卡访问由宿主应用实现。

### ACC Data 嵌入式 Model

`projects/acc_data/inc/model.h` 和 `src/model.c` 是传感器、PMU、按键和存储事件的 ESP-IDF/FreeRTOS 适配层。它依赖 ESP-IDF 类型和硬件服务，因此不参与 Windows SDL 构建。`model_post_*()` 在任务上下文中向队列投递事件，接口没有声明为 ISR 安全。

## 常见运行问题

- Hair Dryer 显示 `Image Not Found`：从仓库根目录通过 `run.bat` 启动，或使用包含 `hair_dryer.c` 的 Release 构建。
- 拖动不能切换页面：按住鼠标左键，沿水平方向移动足够距离后再松开。
- ACC Data 曲线不变化：独立模拟器不会生成样本，需要把数据源连接到 `acc_data_push_sample`。
- 启动了错误的程序：`build.bat` 和 `run.bat` 应使用相同的项目参数及 Debug/Release 配置。
