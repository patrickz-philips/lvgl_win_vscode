# 构建说明

本文档描述根目录 CMake 工程和批处理脚本当前实现的 Windows 构建流程。程序操作和模块 API 参见[使用说明](使用说明.md)，静态独立运行与 DLL 依赖构建的区别参见 [STANDALONE.md](STANDALONE.md)。

## 仓库结构

根仓库负责 SDL 显示/输入宿主、LVGL 调度、项目选择和最终的 `main.exe`。以下目录是 Git submodule：

- `lvgl/`：LVGL 源码依赖。
- `FreeRTOS/`：可选 FreeRTOS 内核依赖。
- `projects/*`：独立版本管理的应用模块。

首次构建前初始化全部依赖：

```powershell
git submodule sync --recursive
git submodule update --init --recursive
```

## 可用项目

| 项目参数 | 源码目录 | 模拟器尺寸 |
| --- | --- | --- |
| `HAIR_DRYER` | `projects/hair_dryer` | 800 x 720 |
| `SMART_SHAVER` | `projects/smart_shaver` | 320 x 640 |
| `CHEETAH` | `projects/cheetah` | 96 x 96 |
| `SLIDE_PLAYER` | `projects/slide_player` | 466 x 466 |
| `BATTERY_MONITOR` | `projects/battery_monitor` | 410 x 502 |
| `ACC_DATA` | `projects/acc_data` | 410 x 502 |

屏幕尺寸由模块公开头文件定义。`src/main.c` 负责适配模块自己的宏名称；模块没有提供尺寸时使用 320 x 480 通用值。CMake 不定义项目屏幕尺寸。

## 环境要求

- Windows 10 或更高版本。
- CMake 3.12.4 或更高版本，并已加入 `PATH`。
- CMake 支持的 C/C++ 工具链，例如 Visual Studio Build Tools。
- vcpkg 位于根仓库同级目录 `../vcpkg`。
- 已为所选 vcpkg triplet 安装 SDL2。
- 仅重新生成 Hair Dryer 图片资源时需要 Python 3 和 Pillow。

预期目录结构：

```text
lvgl_projects/
|-- lvgl_win_vscode/
`-- vcpkg/
```

安装默认静态 SDL2：

```powershell
..\vcpkg\vcpkg.exe install sdl2:x64-windows-static
```

## 构建

从仓库根目录执行：

```powershell
.\build.bat [PROJECT] [Debug|Release]
```

两个参数都可省略，默认值为 `HAIR_DRYER Debug`，参数不区分大小写。

```powershell
.\build.bat SMART_SHAVER Debug
.\build.bat CHEETAH Debug
.\build.bat SLIDE_PLAYER Release
.\build.bat BATTERY_MONITOR Debug
.\build.bat ACC_DATA Release
```

默认 triplet 是 `x64-windows-static`。如需 DLL 依赖版本，可通过环境变量覆盖；切换 triplet 前必须清理该项目缓存：

```powershell
..\vcpkg\vcpkg.exe install sdl2:x64-windows
.\clean.bat HAIR_DRYER
$env:VCPKG_TARGET_TRIPLET = "x64-windows"
.\build.bat HAIR_DRYER Debug
Remove-Item Env:VCPKG_TARGET_TRIPLET
```

输出按配置和项目隔离：

```text
build/<Debug|Release>/<project>/
bin/<Debug|Release>/<project>/main.exe
```

## 运行

运行参数必须与成功构建时一致：

```powershell
.\run.bat BATTERY_MONITOR Debug
```

`run.bat` 从仓库根目录启动程序，确保运行时资源的相对路径有效。

## 清理

```powershell
.\clean.bat [TARGET]
```

| 目标 | 删除内容 |
| --- | --- |
| `all` 或省略参数 | 整个 `build/` 和 `bin/` |
| `build` | 整个 `build/` |
| `bin` | 整个 `bin/` |
| 项目参数 | 该项目在 `build/`、`bin/` 下的 Debug 和 Release 目录 |

## 手动使用 CMake

每个项目、配置和 triplet 应使用独立构建目录：

```powershell
cmake -S . -B build/Debug/hair_dryer `
  -DCMAKE_BUILD_TYPE=Debug `
  -DSELECTED_PROJECT=HAIR_DRYER `
  -DVCPKG_TARGET_TRIPLET=x64-windows-static `
  -DCMAKE_TOOLCHAIN_FILE="../vcpkg/scripts/buildsystems/vcpkg.cmake"
cmake --build build/Debug/hair_dryer --config Debug -j
```

常用可选参数：

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `USE_FREERTOS` | `OFF` | 构建实验性的 FreeRTOS 宿主路径 |
| `LVGL_PRO_PROJECT_DIR` | 空 | 加入包含 `CMakeLists.txt` 的 LVGL Pro 工程 |
| `LV_USE_DRAW_SDL` | `OFF` | 启用 SDL draw unit 和 SDL2_image |
| `LV_USE_LIBPNG` | `OFF` | 链接 libpng |
| `LV_USE_LIBJPEG_TURBO` | `OFF` | 链接 libjpeg-turbo |
| `LV_USE_FFMPEG` | `OFF` | 链接 FFmpeg |
| `LV_USE_FREETYPE` | `OFF` | 链接 FreeType |

常规宿主关闭 LVGL examples、demos 和内部 ThorVG。`USE_FREERTOS=ON` 当前构建 `src/freertos_main.c` 中的独立演示路径，不会初始化所选项目模块。

## 资源处理

- Hair Dryer Debug 在运行时加载 PNG，Release 编译 `hair_dryer.c`。
- Cheetah 编译 CMake 中明确列出的 C 图片资源。
- Slide Player 编译数字命名的 `assets/*.c`；找不到资源时配置失败。
- Smart Shaver、Battery Monitor 和桌面 ACC Data UI 不在根构建中加入图片资源。
- `projects/acc_data/src/model.c` 是 ESP-IDF 嵌入式适配层，不参与 Windows SDL 构建。

## Submodule 开发

修改项目模块后，先在子仓库提交并推送，再更新根仓库 gitlink：

```powershell
git -C projects/<name> status
git -C projects/<name> add <files>
git -C projects/<name> commit -m "..."
git -C projects/<name> push
git add projects/<name>
```

根仓库不能引用远端无法获取的子模块提交。

## 常见问题

### 找不到 vcpkg

确认相对路径 `../vcpkg/scripts/buildsystems/vcpkg.cmake` 存在，不要在构建文件中加入机器相关的绝对路径。

### 找不到 SDL2

为脚本显示的准确 triplet 安装 SDL2：

```powershell
..\vcpkg\vcpkg.exe install sdl2:x64-windows-static
```

### CMake 缓存过期

只清理受影响项目后重建：

```powershell
.\clean.bat SLIDE_PLAYER
.\build.bat SLIDE_PLAYER Debug
```

### 子模块目录为空

```powershell
git submodule sync --recursive
git submodule update --init --recursive
```
